# Manus (manus.im) — inspiration / AI generation, NOT a dependency

**Important:** Manus is a general-purpose autonomous AI agent platform (SaaS), **not** a code
or design library. You do not `npm install` it and it is not a build-block alongside the
others. It's in this toolkit as an *inspiration and first-draft generation* source.

- **Site:** https://manus.im
- **Category:** Autonomous general-purpose AI agent — executes multi-step tasks (research,
  coding, data analysis, browser automation, slides, images, and website/app generation)
  from a prompt.
- **Corporate status:** Acquired by **Meta (Dec 2025)**; continues operating its
  product/subscription from Singapore. (https://manus.im/blog/manus-joins-meta-for-next-era-of-innovation)
- **Pricing:** Tiered subscription SaaS (exact current numbers not verified here).

## How it fits "building cool sites"
- **First draft / scaffolding**: prompt Manus to generate a starting site or section, then
  bring it into the project and refine it by hand with the real toolkit (anime.js / Motion /
  Kokonut / Bklit) so it fits the stack and conventions.
- **Inspiration**: use Manus outputs as reference/mood, not as production code to paste blindly.

## Cautions
- Generated code is a starting point, not a deliverable — review, refactor to project
  conventions, strip secrets, and verify a11y/performance before shipping.
- It's an external paid platform, not part of the repo's dependencies.
- Don't treat it as interchangeable with the animation libs — different category entirely.
