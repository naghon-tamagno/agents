Generate a handoff summary of the current state of the work$ARGUMENTS.

Include, briefly:
1. **Goal** we're pursuing.
2. **What's done** so far (concrete changes, files touched).
3. **Current state**: what works, what's half-done, what still needs verifying.
4. **Next steps**, concrete and in order.
5. **Key decisions and assumptions** made.
6. **Risks / things to be careful about**.

Write it so another person (or you, in another terminal / tomorrow) can pick it up with no
prior context. If it makes sense, propose saving it to a file in the project.
